# PPTX 转高中园 Beamer

把本地 `.pptx` 转成高中园主题的 Beamer 工程，读取原 PPT 动画时间树，保留可识别对象的点击顺序。所有处理在本机进行，不调用外部模型，不需要打开 PowerPoint，不执行 PPT 内嵌的对象或宏。

## 最方便的用法

双击本目录的 `转换课件.cmd`，在窗口中选择一个或多个 PPTX；也可以把文件拖到这个入口上。工具会在原文件旁新建 `课件名_Beamer/`，自动编译放映版和讲义版。已有输出目录会保留，新任务使用带时间戳的目录。

**自动转换结果是初稿。** 请检查 `conversion-report.json` 和 `动画对照表.csv`，逐页核对内容、数学和版面。当前“集合”课件已另外完成逐页审核与原生公式重排，可直接打开该课件的现有 Beamer 工程。

环境要求：Python 3.10+、XeLaTeX（TeX Live 或 MiKTeX）。解析器仅依赖 Python 标准库。EMF/WMF 预览转换需 Windows 的 PowerShell 与 System.Drawing；本机入口会优先使用 Codex 自带 Python。生成的工程使用标准 LaTeX 包，复制到其他系统后可以编译；缺少微软雅黑时会使用 Fandol 字体。

## 命令行

在仓库根目录运行：

```powershell
python tools/pptx_to_beamer/pptx_to_beamer.py "课件路径.pptx" --compile
```

指定输出位置和主题目录：

```powershell
python tools/pptx_to_beamer/pptx_to_beamer.py "课件路径.pptx" --output "新输出目录" --theme "教学课件/高中园Beamer模板" --compile
```

仅读取内容、对象 ID 和动画顺序：

```powershell
python tools/pptx_to_beamer/pptx_to_beamer.py "课件路径.pptx" --inspect-only --output "新的检查目录"
```

命令行不会覆盖非空目录，避免丢失后来编辑的 TeX。

## 输出文件

| 文件 | 用途 |
| --- | --- |
| `main.tex` | 放映版入口，逐步揭示内容 |
| `handout.tex` | 讲义版入口，每页只保留最终可见状态；含教师答案 |
| `slides/slide-XX.tex` | 可逐页修改的正文，每个内容块带原页码和对象 ID |
| `build/main.pdf`、`build/handout.pdf` | 编译结果，默认不提交 Git |
| `assets/` | 高中园主题图片 |
| `source-media/` | 本工程实际引用的原图或 OLE 预览 |
| `inspection.json` | 源文件 SHA-256、按实际顺序列出的幻灯片、对象和动画证据 |
| `动画对照表.csv` | 原页码、点击次序、目标对象、原效果及替代方式 |
| `conversion-report.json` | 转换限制、审核配置状态及逐页说明 |

`build/media/` 中的中间素材可重新生成，不参与正式素材引用。源 PPTX 始终保持原样。文件中的文字只作为课件内容转义，不作为转换指令执行。

## 动画的处理范围

- 首次进入一页是第 1 步；每次原 `clickEffect` 对应下一步。保留先看题、再看答案、最后看解析的点击顺序。
- 支持对象级进入、退出、再次进入，以及组合对象与子对象的可见性约束。组合只增加一次点击，不给每个子形状多加点击。
- `withEffect` 和 `afterEffect` 合入所在点击的最终状态，并报告丢失的时间延迟。连续飞入、百叶窗、盒状等运动改为出现/消失，不宣称逐帧还原。
- 交互触发器、段落/子对象动画、强调、路径动画等会列为需复核；这些情况不能据自动稿认定动画已正确保留。
- 隐藏幻灯片不进入最终放映。讲义版只显示每页最后一步可见的对象，避免已退出对象重新出现。

PDF 中每个揭示状态是一页，放映时按右箭头或翻页键推进；这不依赖 PDF 阅读器对转场动画的支持。

## 当前自动版面的限制

自动稿读取幻灯片层的文字、图片、组内坐标和 OLE 静态预览，将正文放在新主题标题栏下。文字转换为统一的可编辑文本；原来的逐字颜色、字体、复杂段落格式、旋转、渐变、装饰线框和母版装饰没有完整复刻。源页已有页眉文字按顶部位置识别，未识别时使用默认页名，需人工调整。

Office 公式在自动稿中只提取可识别的符号文本，并提示审核。OLE 题目在自动稿中保留为高清预览图片，不冒充可编辑公式。不支持的图表、表格、SmartArt 会写入逐页报告，不应忽略这些报告后直接上课。

## 将一份课件整理成审核版

“集合”课件示例：

```powershell
python tools/pptx_to_beamer/pptx_to_beamer.py "教学课件/2026.09/必修一/1.1.1集合/1.1.1集合.pptx" --reviewed "教学课件/2026.09/必修一/1.1.1集合/1.1.1集合.beamer.json" --output "tmp/集合重新生成" --compile
```

审核 JSON 明确保存页面标题、内容块位置、LaTeX 正文和原对象 ID。`source_sha256` 必须匹配原文件，防止把旧动画顺序用于新版课件。每个内容块的 `ids` 自动继承原对象的动画，工具拒绝合并可见时机不同的对象，也会拒绝遗漏未说明的文字或图片。

```json
{
  "source_sha256": "从 inspection.json 复制完整 SHA-256",
  "slides": {
    "2": {
      "title": "学习目标",
      "blocks": [
        {"ids": ["2"], "x": 70, "y": 180, "w": 1140, "font": 13,
         "tex": "理解集合的含义。"}
      ],
      "ignore": {},
      "notes": ["记录改动来源及理由"]
    }
  }
}
```

坐标按 1280×720 设计画布填写。标题栏占上方约 100；正文建议 `x=70`、`w=1140`、`y>=145`。`font` 是 Beamer 页面中的 pt；正文通常为 11–14。图片块使用 `from_id` 指向原图片对象，并填写 `w`、`h`。同一源对象可拆成多个内容块，仍同时出现。

**审核 JSON 的 `tex` 是可执行的 LaTeX 源码。只对自己编写或已经检查的配置使用 `--reviewed`。** 工具不会自动加载 PPT 内的脚本、备注要求或同名 JSON。

后续可直接提出“用 PPTX 转 Beamer 工具处理这个课件，保留点击顺序，并完成逐页数学和动画核对”，按同一流程生成自动稿、编写审核配置、编译及检查。

## 验证

```powershell
python -m unittest discover -s tools/pptx_to_beamer -v
```

测试覆盖进入前隐藏、退出与再次进入、组/子对象同步、同一次点击的多个效果、段落动画告警，以及文本转义。单元测试只能验证转换逻辑，不能替代数学与视觉检查。
