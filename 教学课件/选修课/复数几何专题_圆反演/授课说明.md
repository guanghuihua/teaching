# 复数几何专题 · 圆反演｜40分钟授课说明

两圆都经过原点，怎样把寻找另一个交点变成求两条直线的交点？从学生已有的正实数乘法出发，让学生用沿原射线伸缩的经验探索反演。几何证明还用到直角三角形相似和直径所对的圆周角。准备方格纸、铅笔和直尺，课前在黑板左侧留出作图区域。

课堂用 [学生投影源码](圆反演.tex) 对应的《圆反演.pdf》。备课及练后核对用 [教师参考源码](圆反演_教师参考.tex) 对应的《圆反演_教师参考.pdf》。题号、来源、预期方法和备选练习见[题库](题库.md)。

## 课堂进程

| 时间 | 教师组织 | 学生要做什么 |
|---|---|---|
| 0—3 分钟 | 出示直线 $x=1$ 上的点和三个像点。暂缓画出完整轨迹，邀请两位学生在图上继续描线。 | 猜像点会落在哪里，并说出还需检验什么。保留猜想，到第16分钟再回看。 |
| 3—10 分钟 | 以 $O$ 为中心、半径取 $2$。规定 $P\ne O$，像点 $P'$ 在射线 $OP$ 上，且 $OP\cdot OP'=4$。投影 INV-01。用学生给出的像点反做一次，引出内外互换、圆周点固定、两次反演回到出发点。 | 在同一射线上标出 $OP=8$ 的点及其像，比较它们与半径的位置，再交换这两个点检查乘积。 |
| 10—16 分钟 | 从 $z'=kz$ 出发，用 $k=OP'/OP$ 推出 $z'=R^2z/\lvert z\rvert^2$。介绍 $\bar z$ 表示关于实轴的对称点，写出等价式 $R^2/\bar z$。INV-02 改用单位圆。 | 先凭几何判断 $i$ 的像，再分别算 $1/i$ 和 $1/\bar i$。在图上指出哪个结果满足同一射线条件。 |
| 16—21 分钟 | 从 $O$ 向直线 $\ell$ 作垂线，垂足为 $H$，取 $H$ 的像 $H'$。从 $H'$ 向射线 $OP$ 所在直线作垂线，标出垂足。请学生指出两个直角和共用的角，完成下述正反两步。 | 用相似三角形说明垂足就是 $P'$。在图上指出以 $OH'$ 为直径的圆，并标出像集少了哪一点。 |
| 21—27 分钟 | 设 $A=(4,0)$、$B=(0,2)$，两圆分别以 $OA,OB$ 为直径。恢复半径 $2$。先请学生写“各圆变成哪条直线”，再揭示两条直线及交点，最后把交点反演回来。 | 先独立写下两条直线的方程。指出在两直线交会处取得的是像点，再计算原来两圆的另一个交点。 |
| 27—33 分钟 | 连续投影 INV-03、INV-04，分别约2分钟和4分钟。巡视时记录一份点像计算和一份图形像说明，供反馈时比较。 | 独立求 $(-2,2)$ 的像，再求以 $O,(0,-8)$ 为直径端点的圆去掉 $O$ 后的像。第二题配图并写直线方程。 |
| 33—37 分钟 | 展示现场作答和教师参考答案。根据纸上证据选择一处反馈，最后请学生亲自修改。 | 用“同射线、距离乘积”核对第一题。用直径的另一个端点及直线方向核对第二题。 |
| 37—40 分钟 | 第一分钟请一人用图解释点的反演。第二分钟请另一人完整说出直线像的条件与结论。第三分钟让全班各写一句话解释求两圆交点时的最后一步。 | 每人留下能独立解释的一步。教师据此判断下次是否要再练“从像还原原图”。 |

## 板书与数学核对

1. **点的反演。** 先写 $OP\cdot OP'=R^2$，旁边画一条有方向的射线并注明 $R>0$、$P\ne O$。由 $OP'=R^2/OP$ 可知，圆外的点移到圆内，圆内的非中心点移到圆外，圆周上的点固定。交换 $P,P'$ 后两个条件仍成立，因此再作一次反演得到原来的 $P$。INV-01 得 $OP'=1/2$。INV-02 中 $i$ 在单位圆上，故像为 $i$。$1/i=-i$，$1/\bar i=1/(-i)=i$。
2. **直线的像。** 设 $O\notin\ell$，$OH\perp\ell$，且 $H\in\ell$。在射线 $OH$ 上取 $H'$ 使 $OH\cdot OH'=R^2$。对 $P\in\ell$、$P\ne H$，从 $H'$ 向 $OP$ 作垂线，垂足为 $Q$。角 $HOP$ 为锐角，所以 $Q$ 在射线 $OP$ 上。由 $\triangle OHP\sim\triangle OQH'$ 得 $OH/OQ=OP/OH'$。于是 $OP\cdot OQ=R^2$，$Q$ 正是 $P'$，且 $\angle OQH'=90^\circ$。当 $P=H$ 时像就是直径端点 $H'$。反过来，取直径圆上除 $O,H'$ 外一点 $Q$，因 $\angle OQH'=90^\circ$，射线 $OQ$ 与 $OH$ 成锐角，故与 $\ell$ 交于唯一的 $P$。同样的相似关系说明 $Q$ 是 $P$ 的像。端点 $H'$ 已处理，$O$ 无原像。这才得到整条直线与去掉 $O$ 的直径圆一一对应。
3. **两圆的交点。** 半径为 $2$ 时，$A'=(1,0)$、$B'=(0,2)$。以 $OA$ 为直径的圆去掉 $O$ 后变成过 $A'$ 且垂直于 $OA$ 的直线 $x=1$，另一圆相应变成 $y=2$。两直线交于 $Q=(1,2)$，故原两圆的另一个交点为 $P=4Q/\lvert Q\rvert^2=(4/5,8/5)$。代入两圆方程可再作核对。该点满足 $x^2+y^2=16/5=4x=2y$。

## 选题与反馈

| 题号 | 选入本课的原因 | 教师核对与反馈依据 |
|---|---|---|
| INV-01 | 先用一条射线建立点与像点的对应，只做一次除法。 | $OP'=1/2$。若纸上只写距离，请学生标出具体位置。若落在反向射线，请补上方向条件。 |
| INV-02 | 单位圆上的 $i$ 是固定点，用它能迅速区分几何反演和复倒数。 | $i$ 保持不动，$-i$ 落在反向射线上。请学生把代数答案与图上的方向配对。 |
| INV-03 | 从射线上的一个距离迁移到第二象限的一对坐标，可同时检查方向和伸缩倍数。 | $\lvert z\rvert^2=8$，倍数为 $4/8=1/2$，故像为 $(-1,1)$。若答案落入别的象限，直接画出原射线检查。 |
| INV-04 | 把课堂定理反向使用，并将直径放在负半轴上，让学生独立确定直线的位置与方向。 | $(0,-8)$ 的像为 $(0,-1/2)$，其余像点在过该点的水平线上，完整像集为 $y=-1/2$。 |

第21分钟若学生仍需整理相似关系，可在黑板保留对应边的比例式，带入两圆应用。到第27分钟转入独立练习。如果 INV-03 用时较长，INV-04 优先完成“端点的像、直线的方向、方程”三步。第37分钟进入学生小结。
