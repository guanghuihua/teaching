# AI伴学结课课：把学习方法带走

45分钟，20个内容页、52个点击状态。高中园模板，数学字体TeX Gyre Termes Math。PDF的一页对应一次点击状态，右下角是内容页编号；左下角不显示时间。

在本目录用XeLaTeX编译两次：

```powershell
xelatex -interaction=nonstopmode "main.tex"
xelatex -interaction=nonstopmode "main.tex"
```

从`main.tex`编辑，保留`beamerthemeGaoZhongYuan.sty`、`book-path.tex`和整个`assets/`。中文优先微软雅黑，缺少时使用Fandol。

放映时先停在题目页，给学生纸笔作答机会。提示按需点击，核对页等收集作答后再揭示。默认不显示答案和教师备注；`HandoutVersion`为备课全显模式，`TeacherNotes`为备注模式。

本课按整门选修课结课设计：复习、独立任务、核验、新主题入门、学习记录、最后5分钟的AI路径检查与小报告整理。报告沿用第一课要求，不新增字数、截止日期或评分比例。
