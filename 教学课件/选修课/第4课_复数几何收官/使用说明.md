# 复数主题收官课

接第3课，45分钟，24个内容页、67个点击状态。主题为《从直角旋转到等边三角形》，完成外拿破仑定理的复数证明，最后5分钟给出内侧变式和AI作业。

用XeLaTeX在本目录编译`main.tex`两次：

```powershell
xelatex -interaction=nonstopmode "main.tex"
xelatex -interaction=nonstopmode "main.tex"
```

保留主题sty、`book-path.tex`和`assets/`。校园版式来自教师指定高中园模板；数学字体为TeX Gyre Termes Math，中文优先微软雅黑，否则Fandol。

PDF全屏后，右箭头或翻页笔每次前进一个点击状态。右下角是内容页编号，左下角不显示时间。先让学生作答或猜测，再揭示；答案与图形标记均由覆盖层控制。顶部`HandoutVersion`为备课全显模式，不用于课堂首屏；`TeacherNotes`为教师备注模式。

内侧作业的完整答案在教师备注和单独的授课说明中，不在最后两页投屏提前公布。
