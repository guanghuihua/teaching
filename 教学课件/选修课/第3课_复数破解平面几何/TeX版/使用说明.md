# 第三课高中园模板版

使用XeLaTeX在本目录编译`main.tex`两次，得到课堂放映PDF。

```powershell
xelatex -interaction=nonstopmode "main.tex"
xelatex -interaction=nonstopmode "main.tex"
```

课件为24个内容页、75个点击状态，共45分钟；PDF的一页对应一次点击状态。默认隐藏答案，翻页逐步揭示。左下角不显示时间。两页复习衔接第2课，最后两页为AI探索与课后作业。

保留`main.tex`、`beamerthemeGaoZhongYuan.sty`、`book-path.tex`和整个`assets/`文件夹。主题及校园图片来自教师指定的高中园模板；几何图形为可编辑TikZ图。

数学字体为TeX Gyre Termes Math，中文优先微软雅黑，否则使用Fandol。正常TeX Live环境包含所需数学字体和宏包。

直接使用默认设置上课。源文件顶部的`HandoutVersion`为备课全显模式；`TeacherNotes`为教师备注模式。
