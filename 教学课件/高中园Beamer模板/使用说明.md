# 高中园 Beamer 模板

由 [[教学课件/高中园模板.pptx|高中园 PowerPoint 原模板]] 转换，保留 16:9 比例、校园拼图、校徽、校训、绿色任务栏和三页结构。

## 使用

打开 [高中园模板.tex](高中园模板.tex)，修改 `\title`、`\author`、`\date`，在 `frame` 环境中填写正文。复制整个文件夹作为新课件，保留主题文件、`book-path.tex` 和 `assets/`。

在模板所在目录使用 **XeLaTeX** 编译：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "高中园模板.tex"
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "高中园模板.tex"
```

预览文件位于 `build/高中园模板.pdf`。`build/` 已忽略，不提交编译中间文件和预览 PDF。

## 常用编辑

```latex
\begin{frame}[t]{任务二：公式展示}
  对任意实数 $a,b$，有
  \[ (a+b)^2=a^2+2ab+b^2. \]
\end{frame}
```

封面使用 `\campusmaketitle`；结束页使用 `\campusclosing`，或 `\campusclosing[谢谢]` 自定义文字。任务页标题建议保持一行，避免进入右上角校名区域。正文可直接使用 Beamer 的 `itemize`、`columns`、`block`、`\pause` 和数学环境。

## 转换范围与素材来源

- `beamerthemeGaoZhongYuan.sty`：可编辑的 TikZ 网格、分隔线、标题栏及文字布局。
- `book-path.tex`：由原 PPTX 第 2 页的自由曲线路径转换，保留矢量书本图标。
- `assets/campus.jpeg`：原文件 `ppt/media/image1.jpeg`，校园照片；按原裁切比例显示。
- `assets/motto.png`：原文件 `ppt/media/image2.png`，校训图片。
- `assets/badge.png`：原文件 `ppt/media/image3.png`，校徽。
- `assets/school-name.png`：原文件 `ppt/media/image4.png`，校名横标。

图片直接提取自用户提供的文件，未重新绘制；其使用范围沿用原素材授权。标题、姓名、日期、正文和数学公式均为可编辑 LaTeX。原 PPT 动画及切换效果未转换；中文字体优先使用微软雅黑，缺少时回退至 Fandol，因此不同系统可能有字形与换行差异。
