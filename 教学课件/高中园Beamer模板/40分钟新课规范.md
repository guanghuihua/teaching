# 40分钟数学新课：固定格式与可调整节奏

本规范是教师选择的备课默认方案，不是课程标准规定的统一分钟数。适用于40分钟新授课；习题课、复习课和明确指定的其他时长另行安排。

| 时间 | 课堂活动 | 学生活动与检查 |
| --- | --- | --- |
| 0—3分钟 | 情境引入 | 识别要解决的问题 |
| 3—10分钟 | 概念探究、条件说明 | 独立思考并解释条件 |
| 10—16分钟 | 例题示范、即时检查 | 至少有一次独立动笔 |
| 16—21分钟 | 性质与依据 | 说明定义怎样产生性质 |
| 21—27分钟 | 应用示范、再次检查 | 暴露典型错误并纠正 |
| 27—33分钟 | 集中独立练习 | 连续完成选定小问，暂不显示答案 |
| 33—37分钟 | 反馈纠错 | 根据板演、巡视证据解释错因 |
| 37—40分钟 | 课堂小结 | 学生回顾概念、条件、方法、自检 |

前27分钟包含引入、探究、讲解和穿插短练，不能排成27分钟连续教师讲授。最后10分钟包含6分钟独立练习和4分钟反馈；最后3分钟固定用于总结。题量随难度调整，“4个小问”是本次对数课的选择，不是每课硬性要求。

## 固定版式

- 16:9高中园模板，数学使用STIX Two Math；数学字母、数字、运算符保持规范字形。
- 每个题目、每个小问独占一张练习页，用 campuspractice 环境，题干后至少35mm纯白空间。长题拆页，不缩小字体挤占板演区。
- 答案另起页，仅教师参考版显示；不在白板演算区域叠加答案。集中练习题之间不插入答案页。
- 课末使用 campussummary，保留3分钟。先请学生说，再由教师补全。
- 学生页面只放教学内容，不写题库路径、生成器、页数、检查说明或备课时间表。

## 题库与授课稿

共享题库保留题目编号、原题来源、答案、目标、方法、预判易错点、难度与评价方式。相同题目不同来源注明重复，不将来源记录数冒充独立题目数。

授课稿按目标只选少量题，题号记录在教师教案或源码注释。默认优先使用教师指定资料；本次对数概念主课优先三维设计。复杂嵌套、技巧题、数学史长计算进入备选题库，不挤占新课基本训练。

## 超时与反馈规则

1. 第21分钟检查进度，优先删备选材料与拓展例题。
2. 第27分钟转入集中练习；如果基础概念仍未建立，减少练习复杂度，保留动笔与反馈。
3. 第37分钟进入小结，不用追加题替代总结。
4. 根据真实板演和巡视决定反馈重点，不预写或虚构班级正确率。

以后复制《高中园模板.tex》即可沿用上述结构。教材目标、题目难度与学生实际需要优先于机械套用分钟数。
