三份课件按提供的 PPT 逐页读取、重排为可编辑的 LaTeX Beamer。保留原有概念、例题、练习和作业，合并重复归纳，拆开密集内容。原 PPT 保持不变。

分步 PDF 用下一页逐次显示解答。`build/` 中还提供每个教学页面只保留最终状态的“静态阅读版”，便于备课浏览。静态阅读版包含答案。

公式、文字、表格均为 TeX；函数图象和选择题图象均由 TikZ/PGFPlots 重绘，没有将原 PPT 页面或公式截图嵌入课件。仅保留高中园模板原有的四幅校园、校徽、校训、校名图片。图象题的干扰选项按照原图关键特征重绘，示意图的相对高低不增加题目数值条件。

## 编译

需要含 `ctex`、Beamer、PGFPlots 的 TeX Live 或 MiKTeX，使用 XeLaTeX。在本目录运行：

```powershell
.\编译课件.ps1
```

也可单独编译某一主文件，两次编译不可省略：模板用到了 TikZ 的页面定位。

```powershell
New-Item -ItemType Directory -Force build | Out-Null
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "4.1.1 有理指数幂.tex"
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "4.1.1 有理指数幂.tex"
```

删去对应 `\pause` 可取消分步；也可在主文件的 `\documentclass` 选项中加入 `handout`，再编译生成所有答案一次显示的版本。修改封面的 `\author` 可填写授课教师。

## 原稿勘误与表述修订

| 原位置 | 问题 | 本版处理及依据 |
| --- | --- | --- |
| 有理指数幂第2页 | “一个数的平方等于5”直接记为正根，遗漏负根 | 区分方程 `x²=5` 的两个解与正方形边长取正值 |
| 有理指数幂第4页 | “n次方程”为笔误 | 改为“n次方根” |
| 有理指数幂第6页 | 混淆先乘方后开方与先开方后乘方，说明中错误地将后者结果也说成与奇偶性有关 | 分为两页；`(ⁿ√a)ⁿ=a` 须根式有意义；`ⁿ√(aⁿ)` 对奇数取 `a`、偶数取绝对值 |
| 有理指数幂第7页 | 底数限制容易在后续运算中被忽略 | 明确正底数、有理指数条件，并补充零的幂与负数奇次根的区别 |
| 有理指数幂第11—12页 | 例4、例5没有列出答案 | 根据原题独立推导并补全；根号范围与原页核对 |
| 幂函数第8页 | 将负整数次幂的两支图象都按奇数指数情形描述 | 区分奇负整数与偶负整数，如 `x⁻¹` 与 `x⁻²` 的左支分别在第三、第二象限 |
| 幂函数第9、13页 | 正半轴上的值域可能被读成整个函数的值域 | 明确“这一部分的值域”，并用 `x³` 与 `x²` 对照完整值域 |
| 幂函数第26页；指数函数第5页 | “不在同一单调区间，否则无法比较大小”过于绝对 | 改为不能直接套用同一单调区间内的性质，跨区间应分类或比较符号 |
| 幂函数第29页 | 原分类未明确列出全部符号组合 | 采用完整符号表，得到 `(-∞,-1)∪(2/3,3/2)`，与原最终答案一致 |
| 幂函数第31页 | 解析中将 `3-2m` 的定义条件写为严格大于0 | 改为非负，随后与大小条件联立；答案仍为 `[-1,2/3)` |
| 指数函数第8页 | 用“没有研究价值”解释排除常函数，表述不准确 | 说明 `a=1` 得常函数，本节定义排除这种情形 |
| 指数函数第28页D项 | 单项中未明示参数底数限制 | 明确补上 `a>0` 且 `a≠1`，保持答案B、D |
| 指数函数第30页 | 将近似小数写成精确相等 | 改为 `1.01³⁶⁵≈37.8`、`0.99³⁶⁵≈0.03` |

幂函数定义沿用原课件“非零实数指数”的教材约定；没有将指数为0的情形加入本课定义。分数次幂的负半轴定义域按对应根式判断，不能把正底数的统一运算法则不加条件地用于负底数。

## 核查与使用范围

- 逐页读取三份原稿，共73页；原例题、练习、表格数值和公式图像对应关系逐项核对。
- 独立推导各题答案，重点检查方根符号、指数运算、定义域和值域、奇偶性、单调区间、不等式端点与参数范围。另以 SymPy 进行55项计算和代数复核。
- 三份主文件均在各自所在目录用 XeLaTeX 编译两次。最终日志无错误、缺字、Overfull/Underfull 排版警告；保留原模板从 Fandol 切换到微软雅黑时的字体重定义提示，不影响输出。
- 检视全部76个教学页面的最终展开状态，并检查分步PDF文字没有超出页面。PDF只含模板的四幅位图，数学图象为矢量曲线。
- 静态阅读版由已核对的分步PDF提取每个教学页面的最终状态，保留矢量内容。

作业页的“书本第113页、同步训练第30页”沿用原课件，未提供对应教材版本及题面，未将这些外部作业题列为已核对题目。使用不同版本教材时请核对页码。原稿中“课本例8、例9”的教材来源名称也未作额外推断。
