## 学习目标与难点

1. 能用非空实数集与对应关系说明函数，并解释“任意一个”和“唯一确定”。
2. 能区分定义域、函数值、值域与集合 $B$，理解值域是 $B$ 的子集。
3. 能正确代入求简单函数值，能依据定义域和对应关系判断两个函数是否相同。

难点是量词的指向：对每个允许的输入，输出必须存在且唯一；不同输入可以有相同输出，$B$ 中可以有未被取到的元素。

按2019版A版组织定义域、对应关系、值域“三要素”，同时强调值域由前两者确定。不同教材对“要素”的称呼可能不同，不能只凭“人教版”三个字混用版本。

## 关键问题与答案

| 页码 | 答案及解释 |
| --- | --- |
| 2 | $x=2$ 时依次为 $5,4,\frac12$；$1/x$ 在 $x=0$ 处无意义。 |
| 3–4 | 购买数量为正整数；运动时间满足 $0\le t\le10$，路程范围为 $0\le s\le30$。购买情境按不限库存的理想模型理解。 |
| 5 | $t=2$ 对应 $22℃$。表格仅以 $\{0,1,2,3,4\}$ 为输入集合，不允许对 $2.5$ 擅自插值。温度值域为 $\{20,21,22\}$。 |
| 9–10 | 输出为 $1,0,1$，构成函数，值域为 $\{0,1\}\subseteq B$。 |
| 11–12 | 甲有输入无输出，乙有输入对应两个输出，均不满足函数定义。乙若改取非负平方根，则成为函数。 |
| 13 | 常函数是函数，定义域为 $\mathbb R$，值域为 $\{2\}$。 |
| 14 | $f(-2)=5,f(0)=1,f(3)=10$，而 $-f(2)=-5$。 |
| 15–16 | ①不同，定义域不同；②相同，自变量字母不影响规则。 |
| 17 | 长方形：$0<x<6$；两实数之和为6：$x\in\mathbb R$。由 $y=9-(x-3)^2$，值域分别为 $(0,9]$ 与 $(-\infty,9]$。完整值域讨论为选做。 |
| 18–19 | 构成函数，值域 $\{0,4\}$；$f(-1)=-1$；两个函数定义域不同。 |
| 21 | 第1题可取 $y=x^2$，限定 $x\in\{-1,0,1\}$；第2题答案为 $7,-1$；选做值域 $(0,9]$。 |
| 23 | 分式定义域 $\mathbb R\setminus\{2\}$，根式定义域 $[-1,+\infty)$，其中 $g(-1)=0$。 |
| 24 | 约分只在 $x\ne1$ 时成立；原分式的定义域不含1，因此与默认定义域为 $\mathbb R$ 的 $g(x)=x+1$ 不同。 |

## 离堂检测如何使用

共4分：第1题判断并说明唯一性1分、值域1分；第2题1分；第3题判断且说明定义域不同1分。评分只用于诊断概念理解。

- 把值域写成 $B$：追问“5由哪个输入得到？”
- 因两个输入对应4而否定函数：让学生逐个检查输入，区分“每个输入唯一”与“每个输出唯一”。
- 代入负数出错：要求写出带括号的代入过程。
- 相同式子便判定同一函数：要求先写出两个定义域。

## 建议板书

$$f:A\to B,\qquad y=f(x),\quad x\in A$$

$A,B$：非空实数集。对任意 $x\in A$，有唯一确定的 $y\in B$。

定义域 $A$；对应关系 $f$；值域 $\{f(x)\mid x\in A\}\subseteq B$。

旁边保留一个正例（平方对应）和两个反例（漏输入、多输出），请学生用定义的词语解释。
