# 高中园数学课件模板

## 文件

- [[高中园数学课件模板.tex]]：可直接复制修改的示例课件
- `sz-campus-beamer.sty`：主题样式文件
- `assets/`：从原始 PowerPoint 中提取的校园建筑、校训、校徽和校名横标
- 原始设计来源：[[../../高中园模板.pptx]]

## 设计对应关系

模板依据原 PowerPoint 的三页版式制作：

- 封面保留校园建筑拼贴、校徽、校训、深绿色标题和作者日期区域。
- 正文保留深绿色页眉、左侧任务标题和右侧校名横标。
- 结束页保留校园拼贴及“敬请批评指正”。

在这三种版式上增加了章节页、概念框、问题框、例题框、提醒框、双栏页和课堂小结页，便于制作数学新授课、概念课和例题课。

主色取自原 PowerPoint：`#126831`。画面比例保持为 16:9。中文优先使用等线，系统没有等线时使用微软雅黑；西文优先使用 Arial。

## 快速使用

复制整个“高中园主题”文件夹，打开 `高中园数学课件模板.tex`，先修改：

```latex
\renewcommand{\CourseTitle}{集合的概念}
\renewcommand{\CourseSubtitle}{必修一 第一章}
\renewcommand{\TeacherName}{华光辉}
\renewcommand{\LessonDate}{2026.09.06}
```

使用 XeLaTeX 编译：

```powershell
xelatex -interaction=nonstopmode "高中园数学课件模板.tex"
```

若有目录或交叉引用，连续编译两次。

## 常用页面

封面和结束页：

```latex
\CampusTitlePage
\CampusEndPage
```

章节过渡页：

```latex
\CampusSectionPage[从情境进入核心问题]{第一部分\quad 情境与问题}
```

普通正文页：

```latex
\begin{frame}{集合的概念}{从具体对象到整体}
  这里填写内容。
\end{frame}
```

教学内容框：

```latex
\begin{definitionbox}[定义]
  这里填写概念。
\end{definitionbox}

\begin{questionbox}[思考]
  这里填写问题。
\end{questionbox}

\begin{examplebox}[例1]
  这里填写题目。
\end{examplebox}

\begin{notebox}[易错点]
  这里填写错误原因。
\end{notebox}
```

逐步显示答案：

```latex
\pause
\answer{这里填写答案。}
\method{这里说明关键方法和依据。}
```

## 使用建议

- 一页集中解决一个教学任务。标题直接说明本页主题。
- 正文字号不要小于模板默认字号；内容太多时优先拆页。
- 定义页同时准备正例和反例，例题页记录学生最可能出现的具体错误。
- 图片放在当前课件目录或单独的 `images/` 文件夹中，并使用相对路径。
- 不修改 `assets/` 中的原始校徽与校名图片比例。

## 来源与边界

本模板是原始 PowerPoint 的 LaTeX 衍生版本，原始文件未被改写。校园图片和校徽等素材来自用户提供的 `高中园模板.pptx`，仅随本教学知识库中的课件使用。
