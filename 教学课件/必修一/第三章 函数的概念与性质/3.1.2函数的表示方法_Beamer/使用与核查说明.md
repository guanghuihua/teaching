# 函数的表示方法：高中园 Beamer 版

## 使用

- [放映入口](main.tex)：31张幻灯片，答案分步显示，编译后为37页PDF。
- [讲义入口](handout.tex)：每张幻灯片保留最终状态，共31页，包含答案。
- [可编辑正文](content.tex)：文字、公式、表格均为原生LaTeX。
- 编译结果为 [放映PDF](build/main.pdf) 和 [讲义PDF](build/handout.pdf)。`build/`忽略，不提交编译产物。

从本目录编译，每个入口连续运行两次，以定位模板中的TikZ页眉和校园封面：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build handout.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build handout.tex
```

## 数学核查与修订

逐题独立推算，并对照原稿检查：

| 原页 | 核查结论 |
| --- | --- |
| 4—5 | 梯形面积为`2x²+30x`，定义域`[10,50]`；三次代入分别为900、1400、2700平方米。 |
| 6—7 | 商品金额逐项等于1.45乘件数；水库表格逐项保留原数据，不推测未列出的函数值。 |
| 9—11 | 温度图保留原曲线，仅作估读；平方根表八组数据均正确，图象端点为(0,0)、(16,4)。 |
| 13—14 | 售出台数为1至10的整数，金额为3000x；10个点不连线。 |
| 16—17 | 三个值域依次为`[1,5]`、`(0,1]`、`[-1,8]`。二次函数顶点为(-1,-1)，右端点为(2,8)。 |
| 19—22 | 结果依次为`x²−1 (x≥1)`、`x²−x+1`、`2x/3−1`；展开或回代符合条件。 |
| 24—25 | 结果依次为`x²−2 (x≤−2或x≥2)`、`2x+7`、`2x−1/x (x≠0)`。 |
| 26—28 | 结果依次为`x³−3x (x≤−2或x≥2)`、`1/(x−1) (x≠0,1)`、`2x+7`、`(2√x+1)/3 (x>0)`。末题回代得到`2√x·(2/√x+1)/3−1=(2√x+1)/3`。 |

对复合函数条件，答案只确定内层表达式值域上的函数值；未据此擅自断言原函数在其他点无定义。

以下为有记录的教学表述修订：

1. 原第7—8页：区分“列出部分数据”和“完整函数表”，避免把部分水深数据表视为完整描述连续函数。
2. 原第10页：连线增加适用条件，防止将离散定义域的点随意连线。
3. 原第15页：将“图象法的前提是变化规律清晰”“列表法的前提是自变量个数较少”改为使用便利性的描述；这些不是定义上的必要条件。
4. 原第19—20、23、25、27页：强调换元后范围与可确定的函数值范围。
