# 广州二中月考（一）：习题讲评

## 文件与使用

- [放映版入口](广州二中月考一_习题讲评.tex)：从用户指定的习题课模板复制，39张幻灯片，编译后含68个揭示状态。按翻页键显示答案与后续推理。
- [讲义版入口](讲义版.tex)：39页，每张幻灯片保留最终状态，含完整答案。
- [题目与解析](题目与解析.tex)：全部19题的可编辑文字与数学公式，复杂解析拆续页。
- [放映PDF](build/广州二中月考一_习题讲评.pdf)、[讲义PDF](build/讲义版.pdf)为本地编译交付。`build/`忽略，不提交生成的PDF和辅助文件。

从本目录编译：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "广州二中月考一_习题讲评.tex"
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "广州二中月考一_习题讲评.tex"
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "讲义版.tex"
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build "讲义版.tex"
```

采用 [[教学课件/习题课模板/习题课模板.tex|习题课模板]] 的16:9比例、10pt、白底衬线字体、居中标题和页码。没有制作无答案学生卷；讲义版也包含答案。
