# 四套期中练习卷：A3合订打印版

本目录中的合订PDF用于一次提交给复印店打印。前半部分为A、B、C、D四套学生卷，后半部分为对应的教师答案、评分细则和教材出处。学生卷不显示题目来源；教师材料保留印刷页码、题号、母题ID及改编说明。

## 打印设置

- 纸张：**A3，横向，420×297 mm**。
- 缩放：**实际大小／100%**。文件已排成双栏，打印时选择“每张纸1页”，无需再设置“一张纸打印2页”。
- 双面：**短边翻转**。全文16个PDF页面，双面打印共8张A3纸。
- 只印学生卷：选择PDF页面 **1—8**，每套用1张A3纸双面打印。
- 只印教师答案与出处：选择PDF页面 **9—16**，每套用1张A3纸双面打印。
- 使用黑白打印即可；中央浅虚线为分栏参考线。首次批量复印前先试印一张，确认机器的短边翻转设置。

这里的页码指PDF阅读器显示的物理页序。每栏页脚保留原卷别与第1—4页，便于核对题目顺序。

| 内容 | PDF物理页 | 双面纸张 |
|---|---|---|
| A卷学生卷 | 1—2 | 第1张 |
| B卷学生卷 | 3—4 | 第2张 |
| C卷学生卷 | 5—6 | 第3张 |
| D卷学生卷 | 7—8 | 第4张 |
| A卷教师答案、评分与出处 | 9—10 | 第5张 |
| B卷教师答案、评分与出处 | 11—12 | 第6张 |
| C卷教师答案、评分与出处 | 13—14 | 第7张 |
| D卷教师答案、评分与出处 | 15—16 | 第8张 |

每套从新的一张纸开始，学生卷与教师答案不会共用同一张纸。左右两栏各保留一张A4页面的原尺寸、原字号及答题留白：正面为原第1、2页，背面为原第3、4页。PDF带有8个导航书签。

## 本次复核结果

2026年10月25日，对4套共76题重新逐题验算，并对照学生题干、教师答案与评分，未发现需要订正的数学错误。未因此改动原题或原答案。记录见[逐题复核记录.csv](逐题复核记录.csv)和[合订复核记录.json](合订复核记录.json)。

重点核对了以下容易误判的地方：

- A卷第11题只给出开区间正半轴上的递增性，不能据此直接比较跨零点的函数值，原答案ABD正确。
- 四卷第16题的重根情况各不相同：A为空集，B为全体实数，C为去掉重根的实数集，D为单点集。四种结论均已重新核对。
- 第15题参数边界、第17题全部最值点、第18题幂函数定义域与单调性证明、第19题指数不等式方向与模型范围，均已逐项检查。
- 20道解答题按实际印出的每一步分值逐小问求和，包括“各1分”“各2分”所对应的两项结论；每卷仍为150分，章节分布仍为30、31、59、30分。单选、多选、填空答案表与对应解析一致。
- 八份原始TeX各重新编译两遍，新编译的32个A4页面与已交付PDF逐页文本、渲染像素一致。合订后的每个半页与对应原页文字一致、字体尺寸一致；教师材料的全部母题ID保留，学生材料无答案和出处标签。

最终合订PDF已逐页渲染检查，确认16个物理页面顺序正确、无漏题、裁切、重叠或缺字，C卷折线图保留清晰，主观题作答空间保留，题目小问连续另行排版。编译日志无TeX错误、缺字及Overfull／Underfull警告。临时渲染和编译产物放在仓库忽略目录 `tmp/midterm_three/`。

## 编辑与重新生成

[main.tex](main.tex) 是合订入口，使用 `pdfpages` 拼入上一级四个卷别目录内的正式PDF；题干和公式仍在原来的各卷 `main.tex`、`教师版.tex` 中编辑。合订入口不把题目转成图片，公式和图形仍以原PDF矢量内容保留。

若修改题目，应同步维护 `tools/textbook_bank/midterm_papers_data.py` 中的题目数据，并重新核对数学、导出及编译相应学生卷和教师版，更新各卷正式PDF后，再运行：

```powershell
python tools/textbook_bank/build_midterm_print_book.py
```

脚本从教学仓库根目录运行，要求Python环境具有PyMuPDF、pypdfium2及XeLaTeX。它会检查原始数据、TeX和正式PDF的一致性、重新编译八份卷子并执行已有数学边界检查，再生成合订PDF及复核记录；一旦发现不一致即停止。逐题文字核查记录也须随题目变更更新，数值检验不能替代证明。重新生成后仍须逐页检查最终PDF。

单独手动编译合订入口时，在本目录内用XeLaTeX运行两遍；生成的 `main.pdf` 与交付文件版面相同。不要将编译辅助文件或临时渲染图加入版本记录。
