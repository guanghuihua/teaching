# 高一数学期中基础过关20题

[打开A4合订打印PDF](期中基础过关20题_A4学生练习及教师讲解.pdf) · [可编辑TeX入口](main.tex) · [20题考点与教材出处](20题考点与教材出处.csv)

适用对象是基础薄弱、临考需要把基础概念和书写步骤落实的学生。严格限定湘教版必修第一册第1—3章及4.1—4.2；20题均由已有教材例题、习题、练习改编，每题10分，共55个小问，训练计200分。题目降低复杂变形，保留端点、重根、等号条件和定义域等真正影响得分的细节。来源不在学生材料中显示，教师材料逐题保留教材页码、题号、母题ID、改编说明及《教材帮》对应页码。

第6（3）、16、18（3）、19（2）稍需迁移，教师可先示范关键步骤，再要求脱稿复做；学生暂时卡在这些步骤时，仍应完成同题其余能写的小问，不要整题空白。上述难度划分是备课预判，尚无班级试测数据。

| 题号 | 对应知识点 | 达标时必须说清或写出的关键 |
|---|---|---|

| 2 | 区间运算、含参并集 | 连接点由谁覆盖，为什么参数可以取等号 |
| 3 | 充分、必要与充要条件 | 双向推出都检查；否定方向给反例 |
| 4 | 全称／存在命题及否定 | 改量词、保范围、改不等号；真假另判断 |
| 5 | 不等式性质 | 负数乘除反向，平方可能等于0 |

| 7 | 基本不等式最值 | 比较量合法、结构定值、等号在范围内可取 |
| 8 | 恒成立 | 配方找最小值，严格与非严格端点不同 |
| 9 | 函数本质、相同函数、值域 | 定义域与对应关系，像集不必取遍B |
| 10 | 定义域 | 根式非负、分母非零，限制取交 |
| 11 | 分段、表格与复合求值、换元 | 先内后外，外层重新选段，括号内是整体 |
| 12 | 图象表示与读图 | 横坐标看域，纵坐标看值，水平线交点判不等式 |

| 14 | 定义证明、单调区间参数 | 任取—作差—定号—结论；轴与区间位置 |
| 15 | 奇函数求值与解析式 | 输入变到已知半轴，整体代入后变号 |

| 18 | 幂函数 | 由点定指数，三种定义域，分区间证明单调性 |
| 19 | 指数函数与绝对值 | 正底数、分界点、值域、同底比较和端点 |
| 20 | 指数衰减模型 | 实际时间范围、底数小于1反向、0不能取到 |

## 建议练习方式与验收

1. 每次5题，分为1—5、6—10、11—15、16—20四组。基础很弱者允许先示范首问，再独立完成其余部分；不以一次完成20题作为唯一要求。
2. 第一轮边讲边订正，评分只定位缺失步骤；第二轮合上答案，在新纸上独立复做错题，不沿抄已有解答。
3. 每题达标需要三项证据：能脱稿写完整；能解释关键条件或端点；教师口头改变一个简单数据后，仍能说明做法。只会背原结果不算掌握。
4. 两次仍错时记录具体原因：分解不会、负号错误、量词遗漏、区间误取、不会把输入变正等，再回到该题知识清单补先修步骤。
5. 最后用已有四套卷之一检验迁移。客观题按原卷规则计分，主观题按原评分；用真实错题决定最后补练内容，不能根据本册训练分虚构正式考试结果。

## 编辑与重新生成

- [main.tex](main.tex) 是唯一主入口，输入[学生题目](学生题目.tex)、[知识清单](知识清单.tex)、[教师讲解](教师讲解.tex)。全部可直接编辑；仅编译主入口。
- 持续维护请同步更新 `tools/textbook_bank/midterm_foundation20_data.py`；运行 `python tools/textbook_bank/build_midterm_foundation20.py` 可重新导出、编译、核查和渲染，但会覆盖本目录四份TeX内容文件。
- 所需环境为XeLaTeX、Windows中文字体及Python的pypdfium2；编译和渲染暂存 `tmp/midterm_foundation20/`，不提交辅助文件。正式合订PDF是有意保留的教学交付件。
- 内容修改后须重新检查数学、评分和最终PDF，不能仅沿用本次核查结论。
