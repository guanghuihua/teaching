# 高一期中考前重点十题 使用与来源

这套资料把所给图片中的7类重点展开为10道解答题，供高一学生在期中考试前完成一次集中复习。重点检查条件、变形依据、解集端点和规范书写。“重点十题”表示对所给材料与题型清单的集中覆盖，不表示对实际考试题目或考点出现概率的承诺。

建议独立作答100分钟，满分100分，每题10分。这是本资料的教学建议，各小问评分分配见教师详解，不代表学校正式考试的时长或评分要求。

学生先完成整卷，再用详解逐项核对。订正时写明错误发生在“条件限制、代数变形、符号判断、端点、取等条件、证明依据”中的哪一步，并重新书写完整过程。只比较最终答案不足以完成订正。

教师可根据学生实际作答选题讲评。第1—4题适合检查基础运算，第5—8题适合检查函数性质与证明，第9—10题适合检查基本不等式的适用条件和取等。每题的目标概念、预期方法、难度、易错点和评价方式记录在 JSON 与教师资料中；这些是教学设计，不是已发生的学生表现数据。

## 原材料发现与取舍

S3和S4的第19题不对应。S4第4页第19题是指数函数 $f(x)=2^x+a\cdot2^{-x}$ 的综合题，S3第4页第19题答案使用的是定义在 $[-1,1]$ 上的有理函数。因此本卷第6题明确记为根据答案题型独立重设，第7题第二问也独立给足条件；不把这份答案作为S4第19题的解答。

S2第15题答案出现第（3）问，而S1学生题目只有第（1）（2）问。本资料不据此补造题干，也不采信该多出小问的题答对应关系。第4题第三问仅依据S1第15题（2）可辨认的原式整理，并补足 $a>0$ 条件后重新推导。

S4实际为4页，页脚却印“共8页”，本说明按物理页定位。S4第17题两小问本身没有发现所述错配问题：第（1）问最大值为1，第（2）问最小值为9，均在 $x=1$ 取得。本卷第9题第二问采用其第（1）问，不将第17题误记为错题。

源答案只作为核对材料。涉及选择题转解答题、补充定义域或正性条件、重设函数与设问的改编，均在上表说明；新增详解、方法步骤和评分建议属于本资料的教学编写。未将无法可靠辨认的公式或题答对应不明的小问作为正式题目收录。

## 可复现构建

四个版本均由 [[教学课件/必修一/期中考试/考前重点十题/十题内容.json|十题内容 JSON]] 经 [[教学课件/必修一/期中考试/考前重点十题/build_materials.py|build_materials.py]] 生成。修改 JSON 后，运行脚本将更新同目录的四个 TeX 文件；若需长期保留手工 TeX 调整，应同步修改构建脚本。Beamer版采用仓库 [[教学课件/习题课模板/习题课模板.tex|习题课默认模板]] 的16∶9结构，参见 [[教学课件/习题课模板/使用说明|模板使用说明]]。学生卷按 [[试题排版规范|学生试卷排版规范]] 单独生成。

需要 Python 3 和 XeLaTeX，TeX依赖由TeX Live提供。`build_materials.py` 不带参数，只生成TeX，不编译PDF。在本目录打开PowerShell后可执行：

```powershell
python .\build_materials.py
New-Item -ItemType Directory -Force -Path '.build' | Out-Null
$texFiles = @(
    '考前重点十题_学生卷.tex',
    '考前重点十题_详解与方法.tex',
    '考前重点十题_Beamer.tex',
    '考前重点十题_Beamer讲义.tex'
)
foreach ($texFile in $texFiles) {
    1..2 | ForEach-Object {
        xelatex '-interaction=nonstopmode' '-halt-on-error' '-output-directory=.build' $texFile
        if ($LASTEXITCODE -ne 0) { throw "编译失败：$texFile" }
    }
    $pdfName = [System.IO.Path]::ChangeExtension($texFile, '.pdf')
    Copy-Item -LiteralPath (Join-Path '.build' $pdfName) -Destination $pdfName -Force
}
```

如在Codex桌面环境重建，应使用工作区依赖加载工具返回的Python绝对路径替换命令中的 `python`。`.build` 用于可复现的TeX编译中间文件，受本目录忽略规则保护；只将有意交付的PDF复制到正式目录。

后续修改题目或答案时，应逐题重新核对条件、等价变形、端点、取等和评分点。编译后查看日志并逐页检查正式PDF的公式、作答区与投影效果，尤其注意Beamer讲义版包含全部答案，学生独立作答应使用学生卷。
