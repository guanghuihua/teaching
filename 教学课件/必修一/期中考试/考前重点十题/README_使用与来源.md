# 高一期中考前重点十题 使用与来源

这套资料围绕原图片中的7类重点，并补充复合函数的定义域与值域，共编排10道大题。课堂材料集中呈现题目、解题步骤、规范解答和易错提醒；来源、改编说明及原材料问题保存在本文件，供教师备课追溯。原始文件保持不变。

“重点十题”表示对所给复习材料和题型清单的集中覆盖，不作实际考试命中承诺。练习进度由教师结合本校范围与课时安排，本资料不再预设总分、每题分值或统一作答时长。

## 十题结构

| 题号 | 内容 | 方法与书写重点 |
| --- | --- | --- |
| 1 | 集合的交并补运算 | 在同一条数轴上用不同高度的蓝色区间括线表示两个集合，端点落在轴上；由包含关系观察交并集，补集须明确全集。 |
| 2 | 教材例1至例6，合并为六小问 | 覆盖两个不同实根、重根、无实根、分式转乘积、严格正值恒成立及由解集反求系数；结合图像、端点与量词规范书写。 |
| 3 | 复合函数的定义域与值域，三小问 | 先理解复合与拆层，认识一次、二次、反比例、指数、幂函数作为外层时的输入条件，再求中间量实际范围与最终值域。 |
| 4 | 指数幂与根式，四小问 | 小数化分数、带分数化假分数、负指数取倒数、根式与分数指数互化；用 $\sqrt{u^2}=\lvert u\rvert$ 并按范围去绝对值。 |
| 5 | 用定义证明单调性 | 必须任取区间内两点；两个具体数字的函数值比较不能证明整个区间的单调性。 |
| 6 | 奇偶性条件与定义证明 | 先检查定义域对称，再计算 $f(-x)$ 并与 $f(x)$ 比较；求出参数后代回验证。 |
| 7 | 奇偶性与单调性解函数不等式 | 统一到同一单调区间，同时保留内层变量属于定义域的条件。 |
| 8 | 利用奇偶性补全解析式 | 在待求区间设变量，把负自变量代入已知式，单独处理原点。 |
| 9 | 基本不等式中的配凑与负号 | 先构造正变量，判断所求为上界还是下界，写出等号与取得点。 |
| 10 | 约束条件下的倒数和最小值 | 利用定和关系作常数代换，联立等号条件并验证可行性。 |

图片的7类重点依次对应：集合第1题；二次与分式不等式第2题；指数幂第4题；单调性与奇偶性证明第5、6题；函数不等式第7题；奇偶性补解析式第8题；基本不等式第9、10题。新增第3题承接指数函数课件，补充复合函数及定义域、值域的基础说明，总数仍为10题。

## 原材料问题与取舍

S9第25页例1（2）的原式为 $y=(\frac32)^{-|x|}$，正确值域是 $(0,1]$，课件原红字答案 $[1,+\infty)$ 有误。本卷未选该小问，也未沿用该答案；第3题的三式分别按其条件重新求解。

S3第19题答案为有限定义域上的有理函数，而S4第19题题干是指数函数综合，二者不对应。因此第6题及第7题第二问均记录为独立重设，不沿用错配关系。S2第15题答案多出第（3）问，S1学生题只有第（1）（2）问，本资料不据此补造题干。S4第17题两问本身正确，不列为错题；本卷仅取其第（1）问用于第9题第二问。

来源答案、原图与原课件均只作为核对依据，不能替代独立推导。补充条件、选择题转解答题、重设题干及新增方法说明均在上表记录；模糊题式与题答对应不明的小问不进入正式练习。

## 可复现构建

`build_materials.py` 读取 `十题内容.json` 与 `math_diagrams.tex`，生成四份TeX，并把图形宏嵌入源文件。修改内容或图形后重新运行脚本，会覆盖对应TeX；需保留的版式调整应同步写入构建脚本。生成的TeX可独立编译。

Beamer沿用 [[教学课件/习题课模板/习题课模板.tex|习题课默认模板]] 的16∶9结构，参见 [[教学课件/习题课模板/使用说明|模板使用说明]]；学生卷按 [[试题排版规范|学生试卷排版规范]] 单独生成，小问连续排列，作答区放在完整大题之后。

需要Python 3、XeLaTeX及TeX Live相应宏包。构建脚本不带参数，只生成TeX。在本目录打开PowerShell后执行：

```powershell
python .\build_materials.py
New-Item -ItemType Directory -Force -Path '.build' | Out-Null
$texFiles = @(
    '考前重点十题_学生卷.tex',
    '考前重点十题_详解与方法.tex',
    '考前重点十题_Beamer.tex',
    '考前重点十题_Beamer讲义.tex'
)
foreach ($texFile in $texFiles) {
    1..2 | ForEach-Object {
        xelatex '-interaction=nonstopmode' '-halt-on-error' '-output-directory=.build' $texFile
        if ($LASTEXITCODE -ne 0) { throw "编译失败：$texFile" }
    }
    $pdfName = [System.IO.Path]::ChangeExtension($texFile, '.pdf')
    Copy-Item -LiteralPath (Join-Path '.build' $pdfName) -Destination $pdfName -Force
}
```

在Codex桌面环境重建时，使用工作区依赖加载工具返回的Python绝对路径替换 `python`。`.build` 与 `.qa` 是本目录忽略的编译、渲染工作目录；只将有意交付的PDF复制到正式目录。

后续修改后，应重新核对每个小问的条件、变形依据、端点及等号，检查定义域与中间量范围，并在编译后查看日志和逐页检查正式PDF。课堂版式还须确认没有来源或评价栏目、没有公式越界，且Beamer分步内容与讲义版本一致。
