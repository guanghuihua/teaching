# 期中基础知识总复习

用于考试前一晚的三节晚自习，范围到指数函数，不含对数。根据教师所述的薄弱基础，课件只安排知识回忆、结论核对和个人补漏，没有例题、计算练习或综合题。它与此前的 [[教学课件/必修一/期中考试/考前重点十题/README_使用与来源|考前重点十题]] 分别承担知识回顾与题型复习。

## 文件与投屏

- [分步放映版 PDF](期中基础知识总复习_Beamer.pdf)：在回忆提示处停留，学生先写，再翻页显示完整知识和易错提醒。同一逻辑页的两次显示使用相同页码。
- [完整显示版 PDF](期中基础知识总复习_完整显示版.pdf)：每个知识页一次完整显示，适合教师备课查看，也可用于课后回看；其中包含全部知识内容。
- [Beamer 源文件](期中基础知识总复习_Beamer.tex)：单文件，可直接用 XeLaTeX 编译，无外部图片依赖。
- [完整显示版源文件](期中基础知识总复习_完整显示版.tex)：相同内容的 `handout` 模式。

## 三节安排

按每节约45分钟安排，可根据学生回忆情况调整停留时间。

| 晚自习 | 内容 | 使用方式 |
|---|---|---|
| 第一节 | 集合、逻辑、不等式 | 集合约10分钟，逻辑约8分钟，不等式约20分钟，末尾回忆补漏约7分钟 |
| 第二节 | 函数概念、性质、五个幂函数 | 概念与范围约12分钟，单调性与奇偶性约15分钟，幂函数约11分钟，回忆补漏约7分钟 |
| 第三节 | 根式、指数幂、指数函数 | 根式与运算约15分钟，指数函数约15分钟，回忆与个人遗漏整理约15分钟 |

每个知识页先显示“先回忆”，点击后显示完整内容。学生只需写出关键结论、公式、条件或步骤，不要求逐字抄录。三节末尾均有遮住知识后的回忆页；最后一页用于整理个人遗漏。课件不含学生表现或效果数据。

## 模板与编译

从 [[教学课件/习题课模板/习题课模板.tex|习题课模板]] 复制，遵循 [[教学课件/习题课模板/使用说明|模板说明]]：16:9、10pt、白底、衬线字体、仅页码。正文使用 `\large`，较多内容拆页；以 `\pause` 实现回忆后点击显示。

在本目录分别连续编译两次：

```powershell
xelatex -interaction=nonstopmode "期中基础知识总复习_Beamer.tex"
xelatex -interaction=nonstopmode "期中基础知识总复习_Beamer.tex"
xelatex -interaction=nonstopmode "期中基础知识总复习_完整显示版.tex"
xelatex -interaction=nonstopmode "期中基础知识总复习_完整显示版.tex"
```

正式PDF为有意交付的教学材料；编译及视觉核查的临时产物放在忽略目录 `.build/`、`.qa/`。

本次交付为46个逻辑页：分步放映版86页，完整显示版46页。两份TeX均连续编译两次，日志无错误、缺字或溢出警告；逐页检查了完整显示版，并核对了回忆提示的隐藏效果。分步版每个逻辑页的最终显示与完整显示版逐页一致。
