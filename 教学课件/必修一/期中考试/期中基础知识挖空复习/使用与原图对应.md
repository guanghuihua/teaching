# 期中基础知识挖空复习

把教师提供的照片中的基础知识提取为填空句、公式填空和性质表，供考试前一晚三节晚自习投屏填写。范围到指数函数，不含对数；不安排例题、计算练习、含参数分类或移动区间最值。

共53个逻辑页，其中47页为知识填空，共262个空。封面、使用说明、三个分节页和收束页不计入知识填空页。

## 使用文件

- [分步投屏版 PDF](期中基础知识挖空复习_Beamer.pdf)：100页。每个知识页先显示横线，翻页后在相同位置显示蓝色答案和必要提醒；两次显示使用同一个逻辑页码。
- [纯挖空版 PDF](期中基础知识挖空复习_纯挖空版.pdf)：53页，全程保留横线，不显示答案和答案屏提醒，适合白板停留填写。
- [答案版 PDF](期中基础知识挖空复习_答案版.pdf)：53页，蓝色答案直接填入横线，便于教师查看。
- [Beamer源文件](期中基础知识挖空复习_Beamer.tex)、[纯挖空源文件](期中基础知识挖空复习_纯挖空版.tex)、[答案源文件](期中基础知识挖空复习_答案版.tex)：均为独立文件，不依赖外部图片。

学生可在纸上按逻辑页号记录，也可在白板横线处填写。先完成一页，再点击核对；用不同颜色补齐漏写的符号、条件和端点。每页通常3—8个空，空的宽度按答案长度设置。

## 三节安排与逻辑页码

| 晚自习 | 逻辑页码 | 内容 |
|---|---|---|
| 第一节 | 4—18 | 集合概念与表示、子集与空集、交并补、充分必要、量词否定 |
| 第二节 | 20—37 | 实数大小、等式与不等式性质、基本不等式、二次不等式、函数概念、区间、分段函数、单调性、最值与奇偶性 |
| 第三节 | 39—52 | 五个幂函数性质表、根式、指数幂与指数函数 |
| 最后整理 | 53 | 回看自己填错或漏填的内容，遮住答案再填 |

第二节知识较密，可把已能准确填写的页快速核对，给函数定义、二次不等式和奇偶性条件留出更多时间。

## 编译与核验

从 [[教学课件/习题课模板/习题课模板.tex|习题课默认模板]] 复制，依据 [[教学课件/习题课模板/使用说明|使用说明]] 保留16:9、白底、衬线字体和页码。正文使用 `\large`，答案通过 `\Gap{宽度}{答案}` 在第二次显示中填入；`\Reveal{提醒}` 只在答案状态出现。

在本目录分别用XeLaTeX连续编译两次，例如：

```powershell
xelatex -interaction=nonstopmode "期中基础知识挖空复习_Beamer.tex"
xelatex -interaction=nonstopmode "期中基础知识挖空复习_Beamer.tex"
```

三个版本均独立核对答案、连续编译两次，并检查空白与答案的逐页渲染。分步版每页首屏与纯挖空版一致，末屏与答案版一致；纯挖空版不含蓝色答案文字。临时编译和视觉核查产物保存在忽略目录 `.build/`、`.qa/`。
