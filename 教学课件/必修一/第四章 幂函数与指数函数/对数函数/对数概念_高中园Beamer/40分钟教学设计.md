# 对数的概念：40分钟教学设计

## 本课达成目标

学生能解释对数表示指数，完成指数式与对数式互化；能写全底数、真数条件；能由定义求值，使用基本恒等式并辨别未知量位置。不会以复杂嵌套或换底运算作为本节入门课的达标门槛。

题目均选自用户指定“三维设计”的第62—63页照片。照片未显示完整版本信息，不补造书名版本、编者或出版年份。来源题号、共享答案与目标见 [[04_题库积累/对数的概念/题目与参考解|题库记录]]。

| 时间 | 教学安排 | 教师观察与调节 |
| --- | --- | --- |
| 0—3 | 由2^x=10引出求指数的需要 | 学生是否区分求底数与求指数 |
| 3—10 | 定义、三个条件；讨论对数值能否为负 | 是否误以为“真数为正”推出“对数为正” |
| 10—13 | LOG-039：5³=125互化，教师示范 | 底数保持不变，指数与真数位置对应 |
| 13—16 | LOG-040：log₂16=4互化，学生独立做 | 教师只在作答后确认2⁴=16 |
| 16—21 | 常用/自然对数、特殊值和两个恒等式 | 用a⁰=1说明log_a1=0，核对N>0 |
| 21—24 | LOG-050：2的负对数指数幂 | 先用负指数取倒数，再用恒等式 |
| 24—27 | LOG-049：2log₃x=4 | 学生先化为log₃x=2，再得x=9；不是log₃(2x)=4 |
| 27—33 | 连续独立完成LOG-044、045、038、048 | 6分钟内不插入教师答案，巡视收集真实错误 |
| 33—37 | 反馈4题，重点解释条件和正负根 | 不预设学生表现，不逐题机械再讲一遍 |
| 37—40 | 学生回顾“含义—条件—恒等式—自检” | 用真数为x²的题解释为什么保留负根 |

## 最后四题的评价依据

| 编号 | 参考答案 | 检查点 | 达标证据 |
| --- | --- | --- | --- |
| LOG-044 | x=-2 | 常用对数 | 能说明10的-2次方是0.01 |
| LOG-045 | x=47 | 互化求未知量 | 写出x+2=49，并核对真数为正 |
| LOG-038 | 0<a<1/2 | 有意义的条件 | 列a>0、a≠1、1-2a>0并取交集 |
| LOG-048 | x=±5 | 真数平方与根 | 真数是x²，两个根均使真数等于25 |

这是形成性检查，不是考试评分表。不虚构班级达标率。若第3、4题有共性错误，反馈时优先处理；若已掌握，请学生说明理由后进入总结。

## 备选题与删减顺序

- LOG-037：复合底数条件，作为基础掌握后的延伸，默认不讲。
- LOG-043：直接互化与两个恒等式各自成立的辨析，适合后续复习。
- LOG-054、055：三重对数及变式，进入题库供下一课或课后选用。
- 对数史与历史表格另存“数学文化附录.tex”，不占本次40分钟主线。

超时先删上述备选内容；主课本身不额外插入它们。第27分钟进入独立练习，第37分钟进入总结。基础仍未建立时减少练习复杂度，保留动笔、反馈与小结。
