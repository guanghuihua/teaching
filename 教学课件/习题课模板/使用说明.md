# 习题课默认模板

以后在本仓库制作习题课或试卷讲评课，默认复制 [[教学课件/习题课模板/习题课模板.tex|习题课模板.tex]] 到当次备课目录，再填题。用户指定其他版式时按当次要求执行。

## 使用步骤

1. 复制 TeX 文件并改成课题名称；模板为单文件，不依赖外置主题或图片。
2. 修改 `LessonTitle`、`LessonSubtitle`、`LessonInfo` 和学习目标。
3. 按需要复制选择／填空、带图、多问、详解续页；删除不需要的页。替换所有“待填写”“待替换”等占位内容。
4. 用 `\pause` 实现先题目、后答案和解析；长推导拆页，不以缩小字号代替分页。
5. 在新文件所在目录执行 `xelatex -interaction=nonstopmode "课题名称.tex"` 两次，检查日志及逐页投影效果。

依赖：XeLaTeX、ctexbeamer、newtxtext/newtxmath、TikZ（TeX Live 可提供）。这是投影课件；`handout` 模式仍包含答案，不能直接当作无答案学生卷。另做学生卷时遵循 [[试题排版规范]]。

## 提取依据

- [[教学课件/2026.04/4.24讲评试卷/平面向量的线性运算.tex|平面向量的线性运算]]：逐题讲评、居中配图、点击揭示答案、长解析续页、归纳提升。
- [[教学课件/2026.04/4.24讲评试卷/三角恒等变换复习.tex|三角恒等变换复习]]：带学习目标的封面、知识结构回顾、分步推导。

共同版式为 16:9、10pt、白底、衬线字体、无导航按钮、仅页码。封面整合为单一标题，避免向量原稿中标题重复。课堂收束页是为复用补充的可选结构。

## 内容核验

模板仅保留结构，不收录原课件题目或答案，不表示原材料已完成核验。每次填题记录目标概念、预期方法、易错点、难度与评价方式（可写在 TeX 注释中），并独立核对来源、条件、计算、图形及答案。课后补充真实卡点与有效解释。

提取时发现的原稿复核提示（未修改原稿）：向量稿“系数和为 1”的等价刻画需要基向量不共线等条件；第5（2）题图中的 P、Q 坐标未使连线经过重心；第6（1）题图中 E 的比例与解答不一致。复用原题前须另行核验，不能直接沿用这些图形。
