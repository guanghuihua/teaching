\subq{1}$\triangle ABC$ 中，$\angle C=90^\circ$ 是 $AB^2=AC^2+BC^2$ 的\blank；
\subq{2}$x>0$ 是 $x\ge1$ 的\blank；

\subq{4}$0<x<2$ 是 $1<x<3$ 的\blank。}
